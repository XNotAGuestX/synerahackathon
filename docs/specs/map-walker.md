# 地图行走：可行性与实施

**产品：** Wayfinder / Talk to Your Building  
**范围：** 地图容器内的可移动人形、方向键、从 A 走到 B，且不能穿墙或穿模  
**状态：** 按本文实施  
**日期：** 2026-10-25  
**界面语言：** 英文（`frontend/src/i18n/en.ts`）  
**决策记录：** `docs/adr/ADR-0002-map-walker.md`

德语摘要：Die Figur ist Darstellung. Wände kommen aus Polygonkanten und Öffnungen des bereits geladenen Plans. Sie berechnet keine Route und schreibt keine Sitzung.

## 1. 可行性

可以做，而且不需要新的接口或新的墙面数据。

现有楼层计划已经足够：

| 已有数据 | 用途 |
|---|---|
| `spaces[].polygon` | 可站立的房间内部；每条边默认是墙 |
| `openings[]` 的 `position`、`width_m`、`space_ids`、`kind`、`step_free` | 门洞。点在墙上，宽度沿墙展开 |
| `closed_ids` | 关闭的门或房间不再可通行 |
| `assets[].footprint` | 已画出的设备占地，必须挡住，否则人形会穿模 |
| 路线 `legs[].points` | A 是本层起点，B 是本层终点。折线来自服务端，前端不另算路线 |

抽样测量（开口到所属房间最近边的距离）：

| 建筑 | 开口数 | 中位 | 最大 | 超过 0.35 m |
|---|---|---|---|---|
| `proc-factory-dev-003` | 85 | 0 | 0 | 0 |
| `resplan-14509` | 7 | 0.08 m | 0.08 m | 0 |
| `proc-campus-dev-000` | 149 | 0 | 0 | 0 |
| `swiss-1689` | 381 | 0.07 m | 0.91 m | 6 |
| `osm-way22744230` | 386 | 0.002 m | 0.87 m | 14 |

工厂和住宅的门就在边上。部分楼梯平台的两个多边形并不共边，开口落在空隙中，离两边约 0.7–0.9 m。因此吸附距离取 **1.05 m**，空隙用门位连通，而不是假设所有门都贴在一条共享边上。

最窄抽样门宽 0.54 m。人形碰撞半径取 **0.16 m**（肩宽 0.32 m），再留 0.04 m，窄于 0.36 m 的开口视为过不去。

不做的事：

- 不新增 API 字段，不改 OpenAPI。
- 前端不计算计分路线。沿路线行走只用已经返回的折线。
- 不把位置写入会话，不跨楼层。走到楼梯或电梯口停在本层。
- 不把室外当成可走区域。入口可以靠近，不能走出楼板。

## 3. 几何

1. 每个房间多边形的每条边先是墙。
2. 对每个开口，在它列出的房间里找 1.05 m 内最近的边。
3. 可通行时，在该边上按 `width_m` 挖洞。两个落点之间再加一条经过开口坐标的通道，这样边界上的采样点也能站立，空隙中的平台也能穿过。
4. 开口 id 或任一侧房间在 `closed_ids` 中：洞改成“关闭的门”。无台阶模式且 `step_free` 为假：洞改成“有台阶”。宽度小于 0.36 m：洞改成“过窄”。
5. 站立点必须在未关闭的房间内，或在通道净空内，并且离阻挡边、设备占地至少 0.16 m。
6. 移动按 0.05 m 子步。中心线碰到阻挡边即停。斜向撞墙时沿仍能走的轴向滑动。

A / B：

- 路线可达，且起点房间在本层：A 是本层第一段折线的第一个点，人形重置到 A。
- 终点房间在本层：B 是本层最后一段折线的最后一个点。进入 0.6 m 即到达。
- 没有路线时仍可在房间内走，不假装有 B。

## 4. 界面

地图已有深色工作台、酸橙色强调、Space Grotesk / DM Sans / DM Mono。本功能不另起一套配色。

地图上的火柴人宽 1.5 m、高 2 m，中心在站立点上。像素大小等于该尺寸乘以当前地图比例，放大变大，缩小变小。向左走时水平翻转。方向键面板浮在页面上，可拖动，可隐藏。

状态：无房间、待命、行走、跟随路线、被墙/门/台阶/设备挡住、到达 B。挡住和到达都有一句英文说明。`prefers-reduced-motion` 沿用全局规则，脚步动画会停。

方向键面板用 `position: fixed` 浮在整页上，拖标题栏可移动，Hide / Show 收起和展开。位置记在 `localStorage`。人形仍画在地图里。

## 5. 实施顺序

1. 写 `frontend/src/domain/walk-field.ts` 和 `walk-field.check.ts`。
2. 写 `frontend/src/rendering/WalkPad.tsx`，挂到 `PlanCanvas`，传入 `stepFree` 和已有的 `closedIds`。
3. 文案进 `en.ts`，样式只用已有变量。
4. 跑 `npm run test:walk`，再跑前端类型检查。
5. 用浏览器走一遍：方向键移动、示例路线的 A/B、跟随路线、窄屏不横向溢出。

## 6. 已知限制

- 开口最近落点若在顶点上，洞会开在角上，弯楼梯平台不一定有一条干净的喉部。
- 跟随路线若服务端折线本身穿墙，人会停下并说明原因，不会另找一条路。
- 不能靠走进电梯换层。
- 位置只留在当前页面，刷新后回到 A 或入口。
