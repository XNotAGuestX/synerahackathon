# Level 3 campus demo

This self-contained campus fixture uses synthetic metre geometry and CC0-1.0 attribution in each `building.json`. Both buildings intentionally reuse floor, room, opening, and connector IDs. `Demo Atrium` has two floors joined by a step-free lift; `Demo Lab` has one floor. The two measured walkways provide a short route and a longer alternative.

Run the offline command flow from the repository root (it creates an isolated workspace under `agent_output/workspaces`):

```bash
UV_CACHE_DIR=/tmp/uv-campus-cache uv run python -m final_agent.workspace \
  --building examples/level34/demo-atrium \
  --building examples/level34/demo-lab \
  --commands examples/level34/commands.json
```

The command file lists buildings, registers both links, routes from the upper lab to the same-numbered room in the other building, renders the selected route, closes the short walkway and renders the longer alternative, then reopens the short walkway and renders the recovered route. No language-model request is made in command mode.

Build directly from a new image (Claude credentials required):

```bash
uv run python -m final_agent --plan examples/level34/new-plan.png
```

The command takes the plan path. Printed dimensions are metres. This single-floor mode uses level/elevation 0 as a local datum and keeps unspecified attribution/license explicitly unknown. Visible scale evidence is converted deterministically; if none exists the result is `needs_calibration`, with navigation unavailable. PNG, JPEG and a one-page PDF are supported. A PDF page is rendered to PNG before the existing calibration path. A PDF with more than one page is rejected; supply one page per floor. For multiple floors, the conversational `create_building_from_plan` tool takes per-floor images, calibrations in a shared frame, measured elevations and confirmed alignment. No unverified inter-floor connection is added.

Review the returned source overlay, then, for example, say “Rename the lab to Lab”, review the new preview, and “Apply; I accept the stated approximate-boundary warnings”. `apply_plan` rejects unresolved geometry/access errors. `correct_plan` can set/add/delete rooms, openings, connectors and equipment; `correct_plan_pixels` accepts calibrated image coordinates. Cancel preserves the current building; undo restores the previous committed draft. Each invocation prints its exact saved workspace directory. Resume it with `uv run python -m final_agent --resume /absolute/workspace/directory`.
